# Генератор паролей (Go версия)

Консольная утилита для генерации безопасных случайных паролей с высокой производительностью.

## Возможности

- 🔐 Генерация криптографически стойких паролей
- ⚙️ Настройка длины и сложности
- 🎨 Кастомные наборы символов
- 🎯 Предустановленные режимы (простой/сложный)
- 📊 Генерация нескольких паролей одновременно
- 🚫 Опция исключения похожих символов
- 💾 Сохранение паролей в файл с меткой времени
- 🔍 Проверка силы пароля с детальным анализом
- 🎮 Интерактивный режим с пошаговым вводом параметров
- 🎲 Diceware - запоминающиеся пароли из английских слов
- ⚡ Высокая производительность
- 💻 Компактный бинарник (~2 MB)

## Требования

Go 1.21+

Нет внешних зависимостей - используется только стандартная библиотека.

## Установка

### Сборка программы

```bash
cd Go
go build -o password-generator.exe
```

### Запуск без сборки

```bash
go run main.go [флаги]
# или
go run .
```

## Использование

### Базовые примеры

```bash
# Генерация пароля по умолчанию (12 символов)
./password-generator.exe

# Пароль заданной длины
./password-generator.exe -l 16

# Генерация нескольких паролей
./password-generator.exe -l 16 -c 5

# Сохранение в файл
./password-generator.exe -l 16 -c 3 -o passwords.txt
```

### Настройка сложности

```bash
# Простой пароль (только буквы и цифры, без похожих символов)
./password-generator.exe -s -l 12

# Максимально сложный пароль (все символы, минимум 20 знаков)
./password-generator.exe -complex

# Пароль без спецсимволов
./password-generator.exe -l 16 -no-special

# Пароль без похожих символов (0, O, l, 1, I)
./password-generator.exe -l 16 -exclude-ambiguous
```

### Детальная настройка

```bash
# Только строчные буквы и цифры
./password-generator.exe -l 12 -no-uppercase -no-special

# Только буквы (без цифр и спецсимволов)
./password-generator.exe -l 16 -no-digits -no-special

# 10 паролей для выбора
./password-generator.exe -l 14 -c 10

# Запуск без сборки
go run main.go -l 16 -c 3 -o passwords.txt
```

## Параметры командной строки

```
-h                        Показать справку
-i                        Интерактивный режим
-l                        Длина пароля (по умолчанию: 12)
-c                        Количество паролей (по умолчанию: 1)
-o                        Сохранить пароли в файл
-show-strength            Показать оценку силы пароля
-custom-chars             Кастомный набор символов (игнорирует другие опции)
-no-uppercase             Не использовать заглавные буквы
-no-digits                Не использовать цифры
-no-special               Не использовать специальные символы
-exclude-ambiguous        Исключить похожие символы (0, O, l, 1, I)
-s                        Простой режим (буквы + цифры, без похожих)
-complex                  Сложный режим (все символы, длина >= 20)
-d                        Режим diceware (запоминающиеся пароли из слов)
-words                    Количество слов для diceware (по умолчанию: 5)
-separator                Разделитель между словами (по умолчанию: "-")
-capitalize               Капитализировать первую букву каждого слова
-add-number               Добавить случайное число в конец
```

### Режим Diceware (запоминающиеся пароли)
```
$ ./password-generator.exe -d
envy-spec-tong-none-poem

$ ./password-generator.exe -d -words 6 -capitalize
Oust-Palm-Bass-Twig-Plan-Wipe

$ ./password-generator.exe -d -add-number
rage-weft-iowa-belt-upon-4364

$ ./password-generator.exe -d -separator "_" -capitalize -add-number
Cage_Duty_Sobs_Newt_Mean_4344

$ ./password-generator.exe -d -c 3

==================================================
  Сгенерировано 3 пароля (diceware)
==================================================

 1. rage-weft-iowa-belt-upon
 2. stay-posh-boat-lame-owls
 3. cage-duty-sobs-newt-mean
```

**Безопасность diceware:**
- Словарь из 2048 английских слов
- 5 слов = ~55 бит энтропии (аналог 16-символьного случайного пароля)
- Легко запоминается и набирается
- Идеален для мастер-паролей

## Тесты

Тесты находятся в файле `main_test.go` и используют стандартный пакет `testing`.

### Запуск

```bash
go test ./...
# или с подробным выводом
go test -v ./...
```

### Покрытие

| Функция | Что проверяется |
|---|---|
| `Generate()` | Длина пароля, флаги типов символов (`-no-uppercase`, `-no-digits`, `-no-special`), гарантия наличия каждого включённого типа, исключение ambiguous символов, custom charset, ошибки при `length < 4` и слишком коротком charset |
| `GenerateMultiple()` | Количество паролей, длина каждого |
| `GenerateDiceware()` | Количество слов, кастомный разделитель, капитализация, добавление числа, ошибки при `words < 3` и `words > 10` |
| `checkPasswordStrength()` | Слабый пароль → `"Слабый"`, сильный → `"Сильный"/"Очень сильный"`, рост score с длиной |
| `pluralizePassword()` | Склонение: 1 → пароль, 2 → пароля, 5/11/100 → паролей, 21 → пароль |
| `removeChars()` | Удаление указанных символов, сохранение остальных |

## Сборка для разных платформ

Go позволяет легко собирать кроссплатформенные бинарники:

```bash
# Windows (64-bit)
GOOS=windows GOARCH=amd64 go build -o password-generator.exe

# Linux (64-bit)
GOOS=linux GOARCH=amd64 go build -o password-generator

# macOS (Intel)
GOOS=darwin GOARCH=amd64 go build -o password-generator

# macOS (Apple Silicon - M1/M2)
GOOS=darwin GOARCH=arm64 go build -o password-generator

# Уменьшение размера бинарника
go build -ldflags="-s -w" -o password-generator.exe
```

## Структура кода

```
Go/
├── main.go          # Основной код программы
├── go.mod           # Go модуль
└── README.md        # Документация
```

Код организован в функции:
- `PasswordGenerator` - структура генератора с RNG
- `Generate()` - генерация одного пароля
- `GenerateMultiple()` - генерация нескольких паролей
- `interactiveMode()` - интерактивный режим
- `saveToFile()` - сохранение в файл
- `pluralizePassword()` - правильное склонение

## Безопасность

- Использует `time.Now().UnixNano()` для seed генератора случайных чисел
- Гарантирует наличие хотя бы одного символа каждого выбранного типа
- Случайное перемешивание символов в пароле
- Без внешних зависимостей

## Особенности Go версии

- Высокая производительность (генерация тысяч паролей в секунду)
- Компактный бинарник (~2 MB)
- Кроссплатформенная сборка
- Статическая типизация
- Кастомный вывод справки с русской локализацией
- Правильное склонение слова "пароль"
- Эффективная работа с памятью
- Алгоритм оценки силы пароля:
  - Оценка длины (до 3 баллов)
  - Проверка типов символов (до 4 баллов)
  - Анализ разнообразия символов (до 2 баллов)
  - Градация: Слабый (< 5), Средний (5-6), Сильный (7-8), Очень сильный (9+)

## Производительность

Go версия значительно быстрее Python версии при генерации большого количества паролей:

```bash
# Генерация 10000 паролей
./password-generator.exe -l 16 -c 10000 -o test.txt
# Выполняется практически мгновенно
```
