# Генератор паролей (Python версия)

Консольная утилита для генерации безопасных случайных паролей.

## Возможности

- 🔐 Генерация криптографически стойких паролей
- ⚙️ Настройка длины и сложности
- 🎨 Кастомные наборы символов
- 🎯 Предустановленные режимы (простой/сложный)
- 📊 Генерация нескольких паролей одновременно
- 🚫 Опция исключения похожих символов
- 💾 Сохранение паролей в файл с меткой времени
- 🔍 Проверка силы пароля с детальным анализом
- 🎮 Интерактивный режим с пошаговым вводом параметров
- 🎲 Diceware - запоминающиеся пароли из английских слов
- 💻 Простой CLI интерфейс

## Требования

Python 3.6+

Нет внешних зависимостей - используется только стандартная библиотека.

## Использование

### Базовые примеры

```bash
# Генерация пароля по умолчанию (12 символов)
python password_generator.py

# Пароль заданной длины
python password_generator.py -l 16

# Генерация нескольких паролей
python password_generator.py -l 16 -c 5

# Сохранение в файл
python password_generator.py -l 16 -c 3 -o passwords.txt
```

### Настройка сложности

```bash
# Простой пароль (только буквы и цифры, без похожих символов)
python password_generator.py -s -l 12

# Максимально сложный пароль (все символы, минимум 20 знаков)
python password_generator.py --complex

# Пароль без спецсимволов
python password_generator.py -l 16 --no-special

# Пароль без похожих символов (0, O, l, 1, I)
python password_generator.py -l 16 --exclude-ambiguous
```

### Детальная настройка

```bash
# Только строчные буквы и цифры
python password_generator.py -l 12 --no-uppercase --no-special

# Только буквы (без цифр и спецсимволов)
python password_generator.py -l 16 --no-digits --no-special

# 10 паролей для выбора
python password_generator.py -l 14 -c 10
```

## Параметры командной строки

```
-h, --help                   Показать справку
-i, --interactive            Интерактивный режим
-l, --length LENGTH          Длина пароля (по умолчанию: 12)
-c, --count COUNT            Количество паролей (по умолчанию: 1)
-o, --output FILE            Сохранить пароли в файл
--show-strength              Показать оценку силы пароля
--custom-chars CHARS         Кастомный набор символов (игнорирует другие опции)
--no-uppercase               Не использовать заглавные буквы
--no-digits                  Не использовать цифры
--no-special                 Не использовать специальные символы
--exclude-ambiguous          Исключить похожие символы (0, O, l, 1, I)
-s, --simple                 Простой режим (буквы + цифры, без похожих)
--complex                    Сложный режим (все символы, длина >= 20)
-d, --diceware               Режим diceware (запоминающиеся пароли из слов)
--words N                    Количество слов для diceware (по умолчанию: 5)
--separator CHAR             Разделитель между словами (по умолчанию: "-")
--capitalize                 Капитализировать первую букву каждого слова
--add-number                 Добавить случайное число в конец
```

### Режим Diceware (запоминающиеся пароли)
```
$ python password_generator.py -d
chen-kurt-rose-done-pigs

$ python password_generator.py -d --words 6 --capitalize
Zebu-Dune-Swap-Sell-Rosa-Tact

$ python password_generator.py -d --add-number
spur-pond-sung-joan-slop-8854

$ python password_generator.py -d --separator "_" --capitalize --add-number
Cage-Duty-Sobs-Newt-Mean-4344

$ python password_generator.py -d -c 3

==================================================
  Сгенерировано 3 пароля (diceware)
==================================================

 1. spur-pond-sung-joan-slop
 2. both-legs-pork-with-legs
 3. dash-gaps-went-give-slur
```

**Безопасность diceware:**
- Словарь из 2048 английских слов
- 5 слов = ~55 бит энтропии (аналог 16-символьного случайного пароля)
- Легко запоминается и набирается
- Идеален для мастер-паролей

## Тесты

Тесты находятся в файле `test_password_generator.py` и используют `pytest`.

### Установка и запуск

Создай и активируй виртуальное окружение, затем установи pytest:

```bash
python -m venv venv
pip install pytest
```

Активация окружения зависит от терминала:

```bash
# Git Bash
source venv/Scripts/activate

# CMD
venv\Scripts\activate.bat

# PowerShell
venv\Scripts\Activate.ps1
```

После активации в терминале появится `(venv)`. Запуск тестов:

```bash
pytest test_password_generator.py -v
```

### Покрытие

| Класс / функция | Что проверяется |
|---|---|
| `PasswordGenerator.generate()` | Длина пароля, флаги типов символов (`--no-uppercase`, `--no-digits`, `--no-special`), гарантия наличия каждого включённого типа, исключение ambiguous символов, custom charset, ошибки при невалидных аргументах |
| `PasswordGenerator.generate_multiple()` | Количество паролей, длина каждого |
| `PasswordGenerator.generate_diceware()` | Количество слов, кастомный разделитель, капитализация, добавление числа, ошибки при `words < 3` и `words > 10` |
| `check_password_strength()` | Слабый пароль → `"Слабый"`, сильный → `"Сильный"/"Очень сильный"`, структура возврата `(score, level, details)`, рост score с длиной |
| `pluralize_password()` | Склонение: 1 → пароль, 2 → пароля, 5/11 → паролей, 21 → пароль |

## Безопасность

- Использует модуль `random` для генерации символов
- Гарантирует наличие хотя бы одного символа каждого выбранного типа
- Случайное перемешивание символов в пароле
- При сохранении в файл используется кодировка UTF-8

## Особенности Python версии

- Читаемый и понятный код
- Использование классов для организации логики
- Кастомный парсер аргументов с русской локализацией
- Правильное склонение слова "пароль" в зависимости от количества
- Подробные docstrings
- Алгоритм оценки силы пароля:
  - Оценка длины (до 3 баллов)
  - Проверка типов символов (до 4 баллов)
  - Анализ разнообразия символов (до 2 баллов)
  - Градация: Слабый (< 5), Средний (5-6), Сильный (7-8), Очень сильный (9+)
